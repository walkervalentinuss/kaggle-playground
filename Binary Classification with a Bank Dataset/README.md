# Kaggle Playground S5E8 - Binary Classification with a Bank Dataset

### setup
1. open anaconda cmd
2. conda info --envs # check available env, if 0, create 1 (not recommended doing project in base env)
3. conda create --name myenv python=3.9 numpy pandas scipy # create conda env with python version desired and library you need
4. conda activate myenv # activate the env
5. conda deactivate # deactivate the env

### link to corresponding dataset
https://www.kaggle.com/datasets/sushant097/bank-marketing-dataset-full
